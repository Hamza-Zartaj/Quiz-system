# Quiz Prompt Examples

## Prompt 1

**Title:** C++ Basics Quiz

**Subject:** Programming Fundamentals

**Class:** BSCS 1st Semester

**Small Description:** A beginner-friendly quiz covering variables, operators, output statements, and simple C++ syntax.

**Prompt:** Create a 10-question quiz for first-semester computer science students about C++ basics. Include multiple-choice, true/false, and short-answer questions. Focus on variables, data types, arithmetic operators, `cout`, simple expressions, and common syntax errors. Keep the difficulty easy to medium and use 1 mark for each question.

## Prompt 2

**Title:** Database Normalization Quiz

**Subject:** Database Systems

**Class:** BSCS 3rd Semester

**Small Description:** A conceptual quiz on normalization rules, keys, dependencies, and database design quality.

**Prompt:** Create a 12-question quiz about database normalization for undergraduate database students. Cover 1NF, 2NF, 3NF, BCNF, primary keys, foreign keys, functional dependencies, partial dependencies, transitive dependencies, and data redundancy. Include mostly multiple-choice questions with a few short-answer questions. Use medium difficulty and assign 1 mark per question.

## Prompt 3

**Title:** Computer Networks Fundamentals

**Subject:** Computer Networks

**Class:** BSCS 4th Semester

**Small Description:** A mixed quiz about networking models, IP addressing, protocols, and basic troubleshooting concepts.

**Prompt:** Generate a 15-question quiz for computer networks students. Include questions about the OSI model, TCP/IP model, IP addresses, subnet masks, DNS, HTTP, TCP vs UDP, routers, switches, and common network troubleshooting commands. Use a balanced mix of multiple-choice, true/false, and short-answer questions. Keep the difficulty medium and use 1 mark for each question.
